# Contributing

Aldra's product repositories are private and contributions are by invitation. If you were invited, thank you.

- Branch from `main` and open a pull request; describe what changed and why.
- Use conventional commits: `type(scope): lowercase summary`, for example `fix(portal): keep the deadline filter on reload`.
- Keep changes small and focused, one logical change per commit.
- Never commit secrets or personal data.

Report vulnerabilities privately, see [SECURITY.md](SECURITY.md).
