# Security policy

If you find a security vulnerability in any Aldra repository or service, report it privately to **kontakt@aldra.pl**. Do not open a public issue or pull request for it.

Include what you found, how to reproduce it, and the affected repository or URL. We will acknowledge your report and keep you informed.

Zgłoszenia podatności prosimy wysyłać prywatnie na kontakt@aldra.pl, bez publicznych zgłoszeń w GitHub.
