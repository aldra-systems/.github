Copies of the Aldra logo and icons for use in this organization profile. The source of truth is the private repo `aldra-systems/brand`; update it there first, then re-copy.

- `logo/`: wordmark, mark, horizontal and stacked lockups (colour, mono dark, mono light, on blue), SVG and PNG.
- `icons/`: favicon, platform icons, and `github-avatar.png` (the organization avatar).

Use the files as supplied. Do not recolor, distort or add effects.
